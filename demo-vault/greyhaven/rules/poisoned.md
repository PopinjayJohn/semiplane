## A flag, and not a rule

A **condition** — and the clearest example of why the boundary between the five kinds
semiplane owns and the kinds a plugin owns is drawn exactly there.

The tabletop can put a placement into a condition, show it in the token list, and
carry it in the state document. It cannot tell you what being poisoned **does**,
because "does" is a rule and semiplane has none. So `condition` is a kind semiplane
owns: every build has it, every system may use it, and none of them gets to redefine
it.

A condition is the one kind where the split runs the *other* way from a creature.
Nobody would argue that semiplane should own `creature`, because a creature's
statistics are the game's whole content. Nobody would argue that it should not own
`condition`, because a condition is a flag the table has to be able to show.

## What it does

You can take an action and an attack action, and nothing else.

The mirror hound on [[north-road]] is carrying it. It came off the moor coated in
something the party has not identified, and it is 12 of 12 and prone and has not moved
since Day 3, which is either a very comfortable poison or a very patient one.

## Why the page exists at all

Because the Game Master needs somewhere to write down which of the four conditions
this campaign means by what, and because a condition is the one thing a table and a
wiki will both want to name. The page is what the wiki can search and what a player can
be handed; the flag in the state document is what the Table can draw.

Keeping them apart is the whole discipline. A page saying "poisoned" and a placement
saying `poisoned` are the same **word** and neither is a copy of the other.
